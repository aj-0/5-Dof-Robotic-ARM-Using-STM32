# 🤖 5-DOF Robotic Arm Using STM32

Control a 5-DOF robotic arm using an STM32 NUCLEO-F411RE. Servo positions are received from an ESP32 over UART and controlled using hardware PWM generated by STM32 timers.

---

## 🏗️ Architecture

```text
Mobile App (Wi-Fi)
        │
        ▼
      ESP32
    (UART TX/RX)
        │
        ▼
STM32 NUCLEO-F411RE
    (PWM Output)
        │
        ▼
 5 × SG90 Servo Motors
        │
        ▼
   5-DOF Robotic Arm
```

## 🔧 Hardware

- STM32 NUCLEO-F411RE
- ESP32
- 5 × SG90 Servo Motors
- 5-DOF Robotic Arm Kit
- External 5V Power Supply

---

## ⚙️ STM32 Peripherals

- GPIO
- USART (UART)
- TIM (PWM)
- RCC
- SysTick
---

## 📚 What I Learned

- Configured **USART** for UART communication between ESP32 and STM32.
- Generated **50 Hz PWM** using STM32 timers for SG90 servo control.
- Manually calculated and updated **PSC, ARR, and CCR** values for precise servo positioning.
- Interfaced multiple servo motors using hardware PWM channels.
  
---
## 🐞 Debugging & Validation

- **ST-LINK Debugger** – Verified firmware execution and peripheral initialization.
- **STM32CubeIDE Breakpoints** – Validated UART data reception and servo control logic.
- **UART Serial Terminal** – Validated communication between ESP32 and STM32.
- **Manual Servo Calibration** – Calibrated each servo's angle limits and PWM pulse widths to achieve accurate joint positioning.
- **Hardware Validation** – Tested each servo individually before integrated 5-DOF arm operation.
